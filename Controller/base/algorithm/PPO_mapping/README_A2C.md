# A2C网络调度算法实现

## 算法概述

基于A2C (Advantage Actor-Critic) 的网络调度算法，专门用于任务节点到物理节点的映射决策。该实现根据您的要求进行了定制化设计，包含预调度模块、负载均衡奖励和智能带宽分配。

## 核心特性

### 1. 状态定义
- **物理节点资源状态**: 每个物理节点的可用CPU和内存资源量
- **任务需求**: 当前任务的CPU和内存需求
- **状态向量**: `[物理节点1_CPU, 物理节点1_内存, ..., 物理节点N_CPU, 物理节点N_内存, 任务_CPU需求, 任务_内存需求]`

### 2. 动作空间
- **动作定义**: 选择将当前任务映射到哪个物理节点
- **动作范围**: `[0, num_physical_nodes-1]`
- **动作掩码**: 只允许选择资源满足任务需求的物理节点

### 3. 预调度模块
- **资源检查**: 验证目标物理节点的CPU和内存是否满足任务需求
- **可行性验证**: 任务只有在通过预调度检查后才会被映射
- **拒绝机制**: 不满足资源需求的任务会被拒绝，获得-1的惩罚

### 4. 奖励设计

#### 负载均衡奖励
根据您的公式设计：
```
τ = max(各物理节点可用资源)
ϕ = mean(各物理节点可用资源)
ω = ϕ / (τ · M)，其中M是物理节点数
R = ω_cpu + ω_memory
```

- **设计理念**: 如果所有服务器资源余量都差不多，则ω接近1/M，负载均衡好
- **惩罚机制**: 如果分布悬殊，则ω很小，奖励被压低
- **拒绝惩罚**: 任务被拒绝时，R += -1

#### 最终奖励
- **带宽分配成功**: +0.5
- **带宽分配失败**: -0.3
- **无成功映射**: -0.5

### 5. 智能带宽分配
集成了基于启发式算法的智能带宽分配策略：
- **链路重要性评估**: 根据虚拟网络中节点的度计算链路重要性
- **带宽分配策略**: 重要链路优先分配更高带宽
- **同节点映射优化**: 映射到同一物理节点的任务获得无限带宽

## 核心组件

### A2CAgent
- **架构**: Actor-Critic架构
  - **特征提取器**: 共享的神经网络层
  - **Actor网络**: 输出动作概率分布
  - **Critic网络**: 输出状态价值估计
- **输入**: 物理节点资源状态 + 任务需求
- **输出**: 物理节点选择概率 + 状态价值
- **训练**: 使用Advantage估计进行策略梯度更新

### A2CNetworkEnvironment
- **状态管理**: 维护物理节点资源状态和任务队列
- **预调度检查**: 验证资源可行性
- **奖励计算**: 实现负载均衡奖励公式
- **带宽分配**: 集成智能带宽分配算法

### SmartBandwidthAllocator
- **链路重要性**: 基于节点度计算
- **分配策略**: 重要性驱动的带宽分配
- **路径优化**: 最短路径带宽检查

## 训练配置

### 环境参数
- `num_physical_nodes`: 物理节点数量
- `physical_cpu_range`: 物理节点CPU资源范围
- `physical_memory_range`: 物理节点内存资源范围
- `task_nodes_range`: 任务节点数范围
- `task_cpu_range`: 任务CPU需求范围
- `task_memory_range`: 任务内存需求范围

### Agent参数
- `hidden_dim`: 隐藏层维度
- `lr`: 学习率

### 训练参数
- `total_episodes`: 总训练轮数
- `batch_size`: 批次大小
- `update_frequency`: 更新频率（每N个episode更新一次）
- `gamma`: 折扣因子
- `value_coef`: 价值损失系数
- `entropy_coef`: 熵正则化系数

## 输出结果

### 训练输出
- `a2c_results/`: 训练结果目录
  - `checkpoints/`: 模型检查点
  - `plots/`: 训练曲线图
  - `training_summary.json`: 训练总结

### 关键指标
- **接受率**: 成功映射的任务比例
- **平均奖励**: episode平均奖励值
- **负载均衡奖励**: 基于ω公式的奖励
- **带宽成功率**: 智能带宽分配的成功比例

## 算法优势

### 1. 简化决策空间
- 每个时间步只需决策一个任务的映射
- 动作空间为O(N)，N为物理节点数

### 2. 预调度保证
- 预调度模块确保资源约束满足
- 避免无效映射，提高训练效率

### 3. 负载均衡优化
- 基于数学公式的负载均衡奖励
- 鼓励资源均匀分布，避免热点

### 4. 智能带宽分配
- 基于链路重要性的带宽分配
- 同节点映射优化，减少网络通信

### 5. 实时响应
- A2C算法支持在线学习
- 适合动态环境和实时调度

## 实验结果示例

训练过程中的典型指标：
- **接受率**: 60%-90%（取决于资源紧张程度）
- **平均奖励**: 逐步上升，收敛到正值
- **负载均衡**: ω值趋向1/M，表示负载均衡改善
- **带宽成功率**: 通常在70%-95%之间

2. **超参数调优**: 不同网络规模可能需要不同的超参数
