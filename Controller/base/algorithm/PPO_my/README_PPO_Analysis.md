# PPO算法实现分析报告

## 概述

本报告分析了基于PPO（Proximal Policy Optimization）算法的网络资源调度系统实现。该系统使用Actor-Critic架构来解决复杂的网络拓扑映射和带宽分配问题。

## 核心架构分析

### 1. Actor-Critic网络结构

#### 1.1 网络组件
- **状态编码器（State Encoder）**
  - 输入：物理网络特征 + 虚拟网络特征 + 决策状态特征
  - 架构：MLP + ReLU + Dropout
  - 功能：将复杂的图结构状态编码为固定长度的向量

- **Actor网络（策略网络）**
  - 映射策略头：输出物理节点概率分布
  - 带宽策略头：输出带宽等级概率分布
  - 功能：根据当前状态选择最优动作

- **Critic网络（价值网络）**
  - 架构：MLP + ReLU
  - 功能：估计当前状态的价值，用于计算优势函数

#### 1.2 网络参数
- 隐藏层维度：128
- 学习率：3e-4
- 优化器：Adam
- 激活函数：ReLU + Dropout

### 2. Sequential决策机制

#### 2.1 决策阶段
1. **节点映射阶段（Mapping Phase）**
   - 将虚拟节点映射到物理节点
   - 考虑CPU、内存等资源约束
   - 输出：物理节点索引

2. **带宽分配阶段（Bandwidth Phase）**
   - 为虚拟链路分配带宽资源
   - 考虑网络拓扑和链路容量
   - 输出：带宽等级

#### 2.2 状态表示
```python

# - CPU总量、内存总量、CPU使用率、内存使用率

# - CPU需求、内存需求

```

## 算法实现细节

### 1. PPO损失计算

#### 1.1 策略损失（Policy Loss）
```python
# 计算动作概率的对数
action_log_prob = torch.log(action_probs[actions[i]] + 1e-8)

# 策略损失 = -log_prob * advantage
policy_loss -= action_log_prob * advantages[i].detach()
```

#### 1.2 价值损失（Value Loss）
```python
# 使用MSE损失
value_loss = F.mse_loss(values_current, targets)
```

#### 1.3 总损失
```python
total_loss = policy_loss + 0.5 * value_loss
```

### 2. 优势估计

#### 2.1 GAE（Generalized Advantage Estimation）
```python
# 计算TD误差
delta = reward + gamma * next_value - current_value

# 计算GAE优势
advantage = delta + gamma * lambda * last_advantage * (not done)
```

- **学习率**：5e-4
